# Cookbooks

Task-oriented, runnable recipes for this project. Each cookbook is a self-contained folder with a README and a runnable notebook.

- [AgentEval Python Evaluation Cookbook: Testing AI Agents](./agenteval-python-evaluation-cookbook/README.md) — Learn how to evaluate LLM agents with agenteval-py: write reliability tests, assert on tool behavior, set pass-rate thresholds, and debug failures.
- [FastAPI + LangChain Semantic Caching with SmartMemo](./fastapi-langchain-semantic-caching/README.md) — Integrate SmartMemo into FastAPI + LangChain to cache LLM responses by semantic similarity, block false positives with a classifier, and cut API costs.
